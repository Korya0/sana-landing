# Sana Landing Page & Assets Repository 🌙

Welcome to the official repository for the **Sana** application landing page and central assets hub.

## 🚀 Overview
This repository contains:
- **Landing Page**: A modern, responsive, and SEO-optimized web page built with Vanilla HTML, CSS, and JS.
- **Project Assets**: Centralized location for app screenshots, animations (`.gif`), and promotional videos (`.mp4`) used across the ecosystem (App, READMEs, Social Media).

## 📁 Structure
- `/assets`: Web-specific assets for the landing page.
- `/github_assets`: High-quality screenshots and animations for the GitHub READMEs.
- `index.html`: The main landing page.
- `style.css`: Premium design system with glassmorphism and animations.
- `main.js`: Interactive logic and AOS (Animate On Scroll) initialization.

## 🌐 Live Demo
Visit the live landing page at: [Korya0.github.io/Sana/](https://Korya0.github.io/Sana/)

## 🛠 Deployment
This project is automatically deployed to **GitHub Pages** using GitHub Actions.
The deployment workflow can be found in `.github/workflows/deploy.yml`.
